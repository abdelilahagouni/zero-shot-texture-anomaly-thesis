OVERLEAF PROJECT -- When Is Self-Similarity Enough? (Agouni, Hussein, Yousfi)

1. Upload: Overleaf -> New Project -> Upload Project -> choose this .zip.
2. Compiler: Menu -> Compiler = pdfLaTeX (default). The bibliography uses biber;
   Overleaf runs it automatically.
3. The Introduction, Literature Review and Methodology are DRAFTED (for Dr. Yousfi's
   request). Read them, check every sentence, and rewrite them in your own words.
   The other sections still have notes and red \todo marks: open sections/04_results.tex. Each paragraph has notes (lines
   starting with %) with its purpose, the facts and the \cite keys to use.
   Replace each red \todo{...} with your own text, then press Recompile.
4. Order suggested by the course PDF: Methods and Results first, Introduction
   and Abstract last. Start where you prefer.
5. Share: Overleaf "Share" button -> add Byan and Dr. Yousfi by e-mail.
   Use History & Revisions to see who changed what.

Tables, figures, equations and all 13 references (with DOIs) are already in
place and verified. In main.tex, remove the % in front of a section's \input line to add it to the PDF.
